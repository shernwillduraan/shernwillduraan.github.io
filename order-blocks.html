Order Blocks

Learn how SMC traders use order blocks as areas of interest after meaningful displacement and structural movement.

LESSON 1

What Is an Order Block?

Lesson Explanation

An order block is commonly taught in SMC as an area associated with the final opposing candle or consolidation before strong displacement. The Academy focuses on context rather than treating every opposing candle as an order block.

Practical Exercise

Find three bullish and three bearish order blocks on historical charts. Record the displacement that followed each one.

LESSON 2

Bullish & Bearish Order Blocks

Lesson Explanation

Bullish order blocks are generally studied below price in bullish scenarios, while bearish order blocks are generally studied above price in bearish scenarios. Location, structure and displacement matter more than the label alone.

Practical Exercise

Mark one bullish and one bearish order block. Identify the preceding structure and the level that would invalidate each idea.

LESSON 3

Validating High-Quality Order Blocks

Lesson Explanation

Not every opposing candle is a high-quality order block. Look for meaningful displacement, a structural reason for the move and useful location. Confluence with liquidity and higher-timeframe context can improve the quality of the area.

Practical Exercise

Compare three order blocks: strong, weak and invalid. Write the evidence that separates them.
