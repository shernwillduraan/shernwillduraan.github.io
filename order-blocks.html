Order Blocks

Learn how SMC traders use order blocks as areas of interest after meaningful displacement and structural movement.

LESSON 1

What Is an Order Block?

An order block is commonly taught in SMC as a price area associated with the final opposing candle or consolidation before a strong displacement move. Definitions vary, so context matters.

PRACTICAL EXERCISE

Find three bullish and three bearish order blocks on historical charts. Record what happened after each formed.

LESSON 2

Bullish & Bearish Order Blocks

A bullish order block is generally studied below price in a bullish scenario, while a bearish order block is generally studied above price in a bearish scenario. Location, structure and displacement matter more than the label alone.

PRACTICAL EXERCISE

Mark one bullish and one bearish order block. Identify the preceding structure and invalidation level.

LESSON 3

Validating High-Quality Order Blocks

Not every opposing candle is a high-quality order block. Look for meaningful displacement, a structural reason and useful location. Confluence with liquidity and higher-timeframe context can strengthen the area.

PRACTICAL EXERCISE

Compare one strong, one weak and one invalid order block. Explain the evidence separating them.
